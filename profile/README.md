### 🤝 Contributing & Security

* **Security Vulnerabilities:** Please do **not** open public issues for security vulnerabilities. Review our [Security Policy](https://github.com/arschaos/.github/blob/main/SECURITY.md) for responsible disclosure.
* **Code Style:** All Rust repositories strictly enforce `clippy` and `rustfmt`. Java projects adhere to standard Maven checkstyle definitions.
